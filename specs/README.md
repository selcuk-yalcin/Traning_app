# Specs directory

Supporting artifacts for **Traning_app** (education presentation engine). The authoritative technical specification is at repository root: **`SPEC.md`**.

## Files

| File | Role |
|------|------|
| `plan.md` | Product and architecture baseline aligned with `SPEC.md`. |
| `roadmap.md` | Execution priorities; keep in sync with root `TODO.md`. |
| `tech-stack.md` | Intended runtime and libraries for this repo’s engine (not `admin_pan`). |

## Workflow

1. Change scope or contracts in **`SPEC.md`** first for non-trivial work.
2. Mirror execution order in **`TODO.md`** / `roadmap.md` if needed.
3. Implement; update specs when decisions diverge from the written baseline.
